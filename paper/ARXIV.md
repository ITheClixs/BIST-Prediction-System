# arXiv submission

The submission package is built from committed sources, not assembled by hand:

```bash
make figures RUN_ID=$(shell grep COMMITTED_RUN_ID Makefile | head -1 | awk '{print $$3}')
make paper AUTHOR="Mehmet Demir Güven" AFFILIATION="Department of Computer Science, ETH Zürich" ADDRESS="8092 Zürich, Switzerland"
make arxiv
```

`make arxiv` stages `paper/arxiv/`, rewrites the figure paths from `../docs/figures/`
to `figures/`, copies in every referenced figure, compiles the staged copy once to
prove it stands alone, and writes `paper/arxiv-submission.tar.gz`. Neither the
staging tree nor the tarball is committed; both are reproducible from the sources
that are.

## Metadata

**Title.** Nothing Beats Zero, and the Standard Tests Cannot Tell: Simulation
Calibration of Forecast Comparison on Correlated Equity Panels

**Author.** Mehmet Demir Güven, Department of Computer Science, ETH Zürich,
8092 Zürich, Switzerland

**Abstract.** Paste the text of the `abstract` environment in `main.tex`.
`make arxiv` prints its character count against arXiv's 1920-character metadata
limit and exits non-zero if it is over.

**Primary category.** `q-fin.ST` — Statistical Finance.

**Cross-lists.** `stat.ME` (Methodology), `econ.EM` (Econometrics),
`q-fin.CP` (Computational Finance).

The primary category is the one whose readers the result is addressed to: the
paper corrects tests that the empirical finance forecasting literature applies
routinely. The statistics and econometrics cross-lists carry the size results,
which are not specific to finance.

**Licence.** CC BY 4.0. The calibration is only useful if other studies can
re-run it at their own design points and reuse the tables, which a
non-commercial or no-derivatives licence would obstruct.

**Comments field.** 36 pages, 16 figures, 20 tables. Code, run bundle and
calibration study at
https://github.com/ITheClixs/Prediction-System-for-Istanbul-Stock-Exchange

**MSC.** 62M20 (prediction theory), 62P05 (applications to actuarial science and
finance), 62F03 (hypothesis testing).

**JEL.** C52 (model evaluation and selection), C53 (forecasting), C12 (hypothesis
testing), G14 (information and market efficiency).

## Checks before upload

| Check | Command |
|---|---|
| The staged source compiles with no external paths | `make arxiv` |
| A `.bbl` is present, so a failed BibTeX run cannot empty the bibliography | included by `make arxiv` |
| No `??` cross-reference or `[?]` citation reaches the page | `pytest tests/test_paper` |
| Every number in the manuscript matches the artifact that produced it | `make verify-claims RUN_ID=...` |
| The abstract fits arXiv's metadata field | printed by `make arxiv` |
| The rendered manuscript is deterministic | `pytest tests/test_paper` |

## Ancillary files

`calibration/study.json` is the artifact behind Section 5 and can be attached as
an ancillary file. It is 151 KB of JSON, carries a content hash over its own
numbers, and is regenerated by `bist-predict calibrate` in about four minutes.
